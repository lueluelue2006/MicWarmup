# 隐私与资源使用

MicWarmup 的生产程序仅观察 CoreAudio 的进程与设备状态，并请求内置输入硬件短时间保持运行。

## 访问什么

- 查找豆包输入法的进程、bundle ID 和程序路径，用于确认目标。
- 查询输入设备是否为内置、是否可用，以及目标进程是否正在使用它。
- 在用户默认设置中保存「自动预热」开关。
- 加载应用自己的封面图片，运行随应用提供的辅助进程。

## 声音、输入与网络

程序不注册音频采样回调，不读取音频样本，不录音，也不读取或模拟键盘输入。没有联网、分析上报或自动更新功能。语音识别仍由输入法负责；输入法自身的数据处理不由本工具控制。

macOS 可能显示麦克风权限提示或使用指示，因为工具请求了输入硬件运行。系统本身的签名检查、权限数据库和诊断行为不属于应用的网络功能。

## 资源代价

观察状态的工作量较小，但硬件保持运行会减少其休眠机会，可能增加耗电。尚未测得可靠的额外功耗。效果、系统音频开销和运行时间取决于设备及其他应用。

连续两分钟没有新启用事件会停止本次请求，也可以随时从菜单栏停止或退出。其他应用仍在使用设备时，停止本工具并不代表整个系统的麦克风已停止。

## 问题反馈

请优先提供系统版本、硬件类型和可复现步骤。提交日志前请检查其中是否含有个人路径、设备信息或其他隐私内容；无需上传声音和日常输入文本。
